\# Travel Expense Splitter – Website UI/UX Design



\## 📌 Project Overview



Travel Expense Splitter is a website UI/UX design concept intended to help people organize trip expenses and manage shared travel costs.



The design focuses on creating a clear, user-friendly interface for planning trips, viewing a dashboard, entering expense information, and keeping travel-related notes.



\## 🎯 Problem Statement



When people travel together, tracking shared expenses and organizing trip-related information can become difficult. This project explores a user interface concept intended to make those activities easier to organize.



\## ✨ Designed Screens



This project includes the following UI screens:



\* Home Page

\* Login Page

\* Sign-Up Page

\* Forgot Password Page

\* Dashboard

\* Create Trip Page

\* General Form

\* Entertainment Page

\* Notes Page

\* About Page

\* Contact Page



\## 🛠️ Tools and Technologies
